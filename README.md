# MY-Investissements

MY Investissements — Plateforme web de gestion d’investissements avec niveaux, dépôts, retraits, suivi du portefeuille et rendements estimés.

## État du projet

Prototype web en cours de développement. Les rendements affichés dans la version actuelle sont des estimations de démonstration et ne constituent pas une garantie de profit.
